# Wanderlust

An Airbnb-inspired property rental platform built with Node.js, Express.js, MongoDB, and EJS. The application allows users to discover properties, create listings, manage accommodations, and share experiences through ratings and reviews.

## Live Demo

🔗 https://wanderlust-lyu3.onrender.com

## Features

- Property listing management (Create, Read, Update, Delete)
- Property search functionality
- Category-based property organization
- Rating and review system
- Detailed property pages
- Responsive user interface
- Server-side validation and error handling
- MongoDB Atlas integration
- Render deployment
